# 면접 대기 관리 시스템

상산고 제45대 학생회 문화기획부 신입 부원 모집 **1차 면접(구술)** 대기 운영을 위한 웹 시스템입니다.
**관리자 PC**와 **키오스크 PC** 두 대를 한 대의 서버로 실시간 연결해 운영합니다.

- **관리자 페이지** `/admin` — 대기자 등록, 조 편성(2~3명), 대기 조 지정 · 조 호출 (엑셀 스타일)
- **키오스크 페이지** `/kiosk` — 현재 **대기 조**의 조원 착석 처리, 입실 안내 팝업(소리 포함)

키오스크는 Figma 시안(네이비 헤더 + 실제 마스코트 · 로고)을 그대로 반영했고, 폰트는 **Pretendard** 를 사용합니다.

---

## 빠른 시작

```bash
npm install
npm start
```

기본 포트는 `3000` 입니다. (`PORT=8080 npm start` 로 변경 가능)

| 화면 | 주소 |
| --- | --- |
| 시작 페이지 | http://localhost:3000/ |
| 관리자 | http://localhost:3000/admin |
| 키오스크 | http://localhost:3000/kiosk |

### 두 대의 컴퓨터로 운영하기
1. 한 대(또는 서버)에서 `npm start` 로 서버를 실행합니다.
2. 그 컴퓨터의 IP 를 확인합니다. (예: `192.168.0.10`)
3. 같은 공유기에 연결된 다른 PC 에서 접속합니다.
   - 관리자 PC → `http://192.168.0.10:3000/admin`
   - 키오스크 PC → `http://192.168.0.10:3000/kiosk` (전체화면 `F11` 권장)
4. 두 화면은 서버를 통해 **실시간 자동 동기화**됩니다.

## 웹에 바로 올리기 (배포)

이 저장소는 배포 설정이 포함되어 있습니다.

### 방법 1 — Render (가장 간단, 무료)
1. https://render.com 가입 후 GitHub 저장소 연결
2. 저장소에 포함된 **`render.yaml`** 을 인식해 자동으로 Web Service 가 생성됩니다.
   (수동 설정 시: Build `npm install`, Start `node server.js`)
3. 배포 후 발급된 주소로 `/admin`, `/kiosk` 접속. WebSocket(Socket.IO) 자동 지원.

### 방법 2 — Docker
```bash
docker build -t interview-waiting .
docker run -p 3000:3000 interview-waiting
```

### 방법 3 — Railway / Fly.io / Heroku 등
`Procfile`(`web: node server.js`) 을 그대로 사용합니다. `PORT` 환경변수는 자동 주입됩니다.

> 무료 호스팅은 파일시스템이 재배포 시 초기화됩니다. 대기 명단을 영구 저장하려면
> 퍼시스턴트 디스크를 붙이고 `DATA_DIR` 환경변수를 그 경로로 지정하세요. (`render.yaml` 주석 참고)

## 사용 방법

### 관리자 페이지 (엑셀 스타일)
- **대기자 등록**: 상단에서 `학번(5자리)` + `이름` 추가, 또는 `10101 홍카이, 10501 홍크리 …`(콤마/줄바꿈) 일괄 등록.
- **대기자 표**: 학번 · 이름 · 성별 · 소속 조 · 착석 여부 · **착석 시각** 을 실시간 확인/삭제.
- **조 편성**: 표에서 체크박스로 **2~3명** 선택 → `조 만들기`.
- **조 & 호출**:
  - **`호출`** 을 누르면 키오스크에 입실 팝업(5초 + 알림음)이 뜨고, **대기 조가 자동으로 다음 조로 넘어갑니다.** (예: 1조 대기 → 1조 호출 → 자동으로 2조 대기)
  - **`대기지정`** 으로 원하는 조를 키오스크 대기 화면에 수동 지정할 수 있습니다.
  - `현재 대기 조` 가 상단에 표시됩니다.

### 키오스크 페이지
- 현재 **대기 조**의 조원 카드만 표시됩니다. (우측 상단에 `N조 대기` 배지)
- 착석 전에는 **빈 의자** + `착석 완료` 버튼. 누르면 안내 동의 팝업 → 체크 후 확정 시 **착석 시각 기록** + 마스코트가 앉습니다.
- 남/여 착석 마스코트가 다릅니다. (남: 코끼리 · 여: 딸기 캐릭터)
- 조가 호출되면 `N조 · 학번 이름, … 면접실로 들어오세요` 팝업이 **5초** 표시되고, 뜨는 순간 **알림음(띵동)** 이 납니다.

> **알림 소리 안내**: 브라우저 자동재생 정책 때문에, 키오스크를 열고 화면을 한 번 클릭/터치하면 소리가 활성화됩니다.

## 성별 자동 판별 규칙
학번 5자리 중 **두 번째·세 번째 자리(NN)** 로 판별합니다.

| NN 값 | 성별 |
| --- | --- |
| `01`–`04`, `09`–`12` | 남자 |
| `05`–`08` | 여자 |
| 그 외 | 미상(남자 아이콘) |

예) `10101` → `01` → 남자 · `10501` → `05` → 여자 · `10905` → `09` → 남자

## 기술 구성
- **서버**: Node.js + Express + Socket.IO (실시간 양방향 동기화)
- **상태 저장**: `data/state.json` (파일 기반, 재시작 시 복구, `DATA_DIR` 로 경로 변경 가능)
- **프런트엔드**: 프레임워크 없는 순수 HTML/CSS/JS, 폰트 **Pretendard**
- **알림 소리**: Web Audio API 로 생성 (외부 음원 불필요)

```
server.js            서버 · Socket.IO 이벤트 · 상태/영속화 · 조 대기 로직
public/
  index.html         시작 페이지
  kiosk.html         키오스크 (Figma 시안 반영)
  admin.html         관리자 (엑셀 스타일)
  css/ js/           페이지별 스타일 / 스크립트
  assets/            마스코트·의자·로고 SVG (원본)
data/                상태 저장 폴더 (state.json 은 git 제외)
Dockerfile / render.yaml / Procfile   배포 설정
```

### 마스코트 · 로고 교체
`public/assets/` 의 SVG 를 같은 파일명으로 덮어쓰면 됩니다.

| 파일 | 용도 |
| --- | --- |
| `chair.svg` | 착석 전(빈 의자) |
| `mascot-male.svg` | 남자 착석 |
| `mascot-female.svg` | 여자 착석 |
| `logo.svg` | 상산고 학생회 문화기획부 로고 |

## Socket.IO 이벤트 요약
| 방향 | 이벤트 | 설명 |
| --- | --- | --- |
| C→S | `applicant:add` / `applicant:addBulk` | 대기자 등록 |
| C→S | `applicant:remove` / `applicant:clear` | 대기자 삭제 |
| C→S | `seat:complete` / `seat:cancel` | 착석 완료/취소 |
| C→S | `group:create` / `group:delete` / `group:clear` | 조 편성/삭제 |
| C→S | `group:setCurrent` | 키오스크 대기 조 수동 지정 |
| C→S | `group:call` | 조 호출(팝업+소리) → 대기 조 자동 다음으로 |
| S→C | `state` | 전체 상태 브로드캐스트 (applicants, groups, currentGroupId) |
| S→C | `group:called` | 키오스크 입실 안내 팝업 + 소리 |
