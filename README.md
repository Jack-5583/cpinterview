# 면접 대기 관리 시스템

상산고 제45대 학생회 문화기획부 신입 부원 모집 **1차 면접(구술)** 대기 운영을 위한 웹 시스템입니다.
**관리자 PC**와 **키오스크 PC** 두 대를 한 대의 서버로 실시간 연결해 운영합니다.

- **관리자 페이지** `/admin` — 대기자 등록, 조 편성(2~3명), 조 호출
- **키오스크 페이지** `/kiosk` — 대기자 착석 완료 처리, 입실 안내 팝업(소리 포함)

키오스크 화면은 Figma 시안을 바탕으로 **푸른색 테마**로 제작했으며, 남/여 착석 마스코트가 다릅니다.

---

## 빠른 시작

```bash
npm install
npm start
```

기본 포트는 `3000` 입니다. (`PORT=8080 npm start` 로 변경 가능)

| 화면 | 주소 |
| --- | --- |
| 시작 페이지 | http://localhost:3000/ |
| 관리자 | http://localhost:3000/admin |
| 키오스크 | http://localhost:3000/kiosk |

### 두 대의 컴퓨터로 운영하기

1. 한 대(또는 별도 서버)에서 `npm start` 로 서버를 실행합니다.
2. 그 컴퓨터의 IP 주소를 확인합니다. (예: `192.168.0.10`)
3. 같은 네트워크(공유기)에 연결된 다른 PC에서 브라우저로 접속합니다.
   - 관리자 PC → `http://192.168.0.10:3000/admin`
   - 키오스크 PC → `http://192.168.0.10:3000/kiosk` (전체화면 `F11` 권장)
4. 두 화면은 서버를 통해 **실시간으로 자동 동기화**됩니다.

> 외부(인터넷)에 공개하려면 Render/Railway/EC2 등에 배포하거나, 포트포워딩/사내망을 이용하세요.
> 상태는 `data/state.json` 에 저장되어 서버를 재시작해도 유지됩니다.

## 사용 방법

### 관리자 페이지
- **대기자 등록**: 학번(5자리) + 이름을 하나씩 추가하거나, `학번 이름` 형식으로 여러 줄을 붙여넣어 일괄 등록합니다.
- **대기자 목록**: 성별·착석 상태·**착석 시각**을 실시간으로 확인하고, 개별/전체 삭제할 수 있습니다.
- **조 편성**: 목록에서 **2명 또는 3명**을 선택하고 `조 등록` 을 누릅니다.
- **조 호출**: 조 목록에서 `📢 호출` 을 누르면 키오스크에 입실 안내 팝업이 뜨고 **알림 소리(띵동)** 가 재생됩니다.

### 키오스크 페이지
- 대기자별 카드가 표시됩니다. 착석 전에는 **빈 의자**, `착석 완료` 버튼이 보입니다.
- `착석 완료` → 안내 동의 팝업에서 체크 후 확정하면 **착석 시각이 기록**되고 마스코트가 앉습니다.
- 조가 호출되면 `학번 이름, … 면접실로 들어오세요` 팝업이 **5초간** 표시된 뒤 사라지며, 뜨는 순간 소리가 납니다.

> **알림 소리 안내**: 브라우저 자동재생 정책 때문에, 키오스크를 열고 화면을 한 번 클릭/터치하면 소리가 활성화됩니다.
> (활성화 전에는 화면 하단에 안내 버튼이 표시됩니다.)

## 성별 자동 판별 규칙

학번 5자리 중 **두 번째·세 번째 자리(NN)** 로 판별합니다.

| NN 값 | 성별 |
| --- | --- |
| `01`–`04`, `09`–`12` | 남자 |
| `05`–`08` | 여자 |
| 그 외 | 미상(남자 아이콘으로 표시) |

예) `10101` → `01` → 남자 · `10501` → `05` → 여자 · `10905` → `09` → 남자

## 기술 구성

- **서버**: Node.js + Express + Socket.IO (실시간 양방향 동기화)
- **상태 저장**: `data/state.json` (파일 기반, 재시작 시 복구)
- **프런트엔드**: 프레임워크 없는 순수 HTML/CSS/JS
- **알림 소리**: Web Audio API 로 생성 (외부 음원 파일 불필요)

```
server.js            서버 · Socket.IO 이벤트 · 상태/영속화
public/
  index.html         시작 페이지
  kiosk.html         키오스크
  admin.html         관리자
  css/               common / kiosk / admin 스타일 (푸른색 테마)
  js/                kiosk.js / admin.js
  assets/            마스코트·의자·아이콘 SVG
data/                상태 저장 폴더 (state.json 은 git 제외)
```

### 마스코트 이미지 교체
`public/assets/` 안의 SVG 를 교체하면 됩니다.

| 파일 | 용도 |
| --- | --- |
| `chair.svg` | 착석 전(빈 의자) |
| `mascot-male.svg` | 남자 착석 완료 |
| `mascot-female.svg` | 여자 착석 완료 |

> 현재 마스코트 SVG는 Figma 시안의 캐릭터를 참고해 재현한 것입니다.
> Figma 원본 에셋으로 바꾸려면 같은 파일명으로 덮어쓰면 됩니다.

## Socket.IO 이벤트 요약

| 방향 | 이벤트 | 설명 |
| --- | --- | --- |
| C→S | `applicant:add` / `applicant:addBulk` | 대기자 등록 |
| C→S | `applicant:remove` / `applicant:clear` | 대기자 삭제 |
| C→S | `seat:complete` / `seat:cancel` | 착석 완료/취소 |
| C→S | `group:create` / `group:delete` / `group:clear` | 조 편성/삭제 |
| C→S | `group:call` | 조 호출(키오스크 팝업 트리거) |
| S→C | `state` | 전체 상태 브로드캐스트 |
| S→C | `group:called` | 키오스크 입실 안내 팝업 + 소리 |
